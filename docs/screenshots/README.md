# Screenshots

Ảnh dùng trong `README.md` và `README.vi.md`. Đặt đúng tên dưới đây là ảnh tự
hiện lên trong cả hai file, không cần sửa gì thêm.

| Tên file | Nội dung cần chụp |
|---|---|
| `player.png` | Nút mic nằm trong thanh điều khiển của player, lúc đang thuyết minh (chấm xanh lá) |
| `subtitles.png` | Phụ đề song ngữ hiện trên bài giảng |
| `controls.png` | Bảng nổi mở ra: chế độ Gốc/Thuyết minh, phụ đề, âm lượng, đổi giọng |
| `options.png` | Trang Cài đặt của extension |

Nên chụp ở chiều rộng 1200–1600 px, cắt sát phần cần nhìn.
